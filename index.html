Setup Quick Commands (Linux Mint Terminal) 
# 1. Update Repository System
sudo apt update && sudo apt upgrade -y

# 2. Install Native PostgreSQL & MySQL Server
sudo apt install -y postgresql postgresql-contrib mysql-server

# 3. Install Python 3, Pip & Virtualenv
sudo apt install -y python3 python3-pip python3-venv

# 4. Install Docker Engine untuk Metabase / Superset
sudo apt install -y docker.io
sudo systemctl enable --now docker
sudo usermod -aG docker $USER

# 5. Jalankan Metabase BI Server di Docker (Port 3000)
docker run -d -p 3000:3000 --name metabase metabase/metabase
Bagian 6

Teknik Belajar Akselerasi Kognitif

1. Teknik Feynman

Jelaskan konsep rumit (misal: *Star Schema* atau *Requirements Traceability*) dengan bahasa sederhana seolah mengajari pemula. Jika tersangkut, buka kembali materi Saylor.

2. Active Recall & Spaced Repetition (Anki)

Gunakan flashcard Anki untuk menguji sintaks SQL kompleks (`DENSE_RANK()`, `LEAD/LAG`) dan terminologi BABOK v3 secara berkala untuk ingatan jangka panjang.

3. Project-Driven Learning

Hindari *tutorial hell*. Segera konversikan modul teori Saylor menjadi skrip SQL dan dokumen BRD riil menggunakan data Kaggle di Linux Mint.

10 Proyek Hybrid BI & BA Praktis

Portofolio praktis gabungan dokumen analisis bisnis dan luaran teknis BI

Proyek #01 Domain: E-Commerce

E-Commerce Customer Churn Analysis

Luaran Business Analysis (BA): Dokumen Spesifikasi Kebutuhan Bisnis (BRD), Pemetaan Customer Journey.
Luaran Business Intelligence (BI): Pipeline SQL ekstraksi retensi, Dashboard Interaktif Churn Prediction & Cohort Analysis.
Dampak Bisnis (Business Impact): Memungkinkan tim pemasaran mengidentifikasi 15% segmen pelanggan berisiko tinggi sebelum churn.
Proyek #02 Domain: Healthcare

Healthcare Patient Wait-Time Optimization

Luaran Business Analysis (BA): Dokumentasi Alur Proses Bisnis Saat Ini (As-Is) dan Usulan (To-Be) BPMN.
Luaran Business Intelligence (BI): Dashboard Pemantauan Bottleneck Antrean Rumah Sakit real-time (Metabase/Power BI).
Dampak Bisnis (Business Impact): Mengurangi rata-rata waktu tunggu pasien di unit rawat jalan sebesar 25%.
Proyek #03 Domain: Supply Chain

Supply Chain Inventory & Procurement

Luaran Business Analysis (BA): Dokumen Kebutuhan Fungsional (FRD) integrasi vendor, Matriks Traceability.
Luaran Business Intelligence (BI): Pemodelan Data Skema Bintang (Star Schema) Pergudangan, Dashboard Turnover Stok.
Dampak Bisnis (Business Impact): Mengoptimalkan biaya penyimpanan gudang dan mencegah out-of-stock hingga 18%.
Proyek #04 Domain: Financial Services

Financial Fraud Detection System

Luaran Business Analysis (BA): Penyusunan Use Case Diagram, Logika Aturan Bisnis Deteksi Anomali.
Luaran Business Intelligence (BI): Query SQL Kompleks Deteksi Transaksi Mencurigakan, Dashboard Alert Risiko Keuangan.
Dampak Bisnis (Business Impact): Mempercepat waktu identifikasi potensi fraud transaksi keuangan dalam durasi < 2 jam.
Proyek #05 Domain: SaaS Product

SaaS Subscription Revenue & MRR Analytics

Luaran Business Analysis (BA): User Stories & Kriteria Penerimaan (Acceptance Criteria) Sistem Billing SaaS.
Luaran Business Intelligence (BI): Dashboard MRR (Monthly Recurring Revenue), Churn Rate, & Customer Lifetime Value (LTV).
Dampak Bisnis (Business Impact): Memberikan transparansi arus kas berulang bagi eksekutif untuk keputusan ekspansi.

Retail Omnichannel Sales Integration
